# Consensus Multi-Inheritance Classification of Mammalian Enteric Neurons

## Source
Based on: "Comprehensive Classifications of Mammalian Enteric Neurons Across Functional, Morphological, and Molecular Modalities" (synthesizing >30 primary sources)

---

## Classification Axes

Enteric neurons are classified along four independent axes:

| Axis | Classes |
|------|---------|
| **A. Morphology** | Dogiel type I, Dogiel type II |
| **B. Electrophysiology** | S-type, AH-type |
| **C. Function** | IPAN, excitatory motor neuron, inhibitory motor neuron, ascending interneuron, descending interneuron, secretomotor neuron, vasodilator neuron, intestinofugal neuron |
| **D. Neurotransmitter** | Cholinergic (ChAT+), nitrergic (NOS1+), VIPergic, dopaminergic, serotonergic |

---

## Axis-Axis Correspondence Matrix

This matrix summarises the empirically observed correspondences across all four axes, compiled from >30 sources. Each row is a consensus functional type. Cells marked **1:1** indicate a near-perfect correspondence suitable for a safe cross-product term. Cells marked **partial** indicate the correspondence holds for some but not all members.

| Functional class (Axis C) | Morphology (A) | Electrophys. (B) | Primary transmitter (D) | Confidence |
|---|---|---|---|---|
| IPAN | Dogiel II (**1:1**) | AH-type (**1:1**) | Cholinergic + substance P + CGRP (**1:1**) | Very high |
| Excitatory motor neuron | Dogiel I (**1:1**) | S-type (**1:1**) | Cholinergic + substance P (**1:1**) | Very high |
| Inhibitory motor neuron | Dogiel I (**1:1**) | S-type (**1:1**) | Nitrergic + VIP + ATP (**1:1**) | Very high |
| Ascending interneuron | Dogiel I (**1:1**) | S-type (**1:1**) | Cholinergic + tachykinins (**1:1**) | High |

### Axis A × Axis B (Morphology × Electrophysiology)

| | AH-type | S-type |
|---|---|---|
| **Dogiel type II** | **IPAN** (safe cross-product) | — (not observed) |
| **Dogiel type I** | — (not observed) | **All non-IPAN classes** (safe cross-product) |

This 2×2 is effectively diagonal: the two axis pairs are nearly synonymous in the ENS. This is the single strongest cross-axis correspondence in the literature.

## Proposed Cross-Product Terms

Below, each proposed term crosses exactly two or more axes where the correspondence matrix shows a **1:1** or near-1:1 mapping. Terms are grouped by the number of axes crossed.

### Two-axis cross-products (Morphology × Electrophysiology)

These capture the strongest single correlation in the ENS. Only two terms are needed:

| Proposed term | Axiom | Definition |
|---|---|---|
| **Dogiel type II AH-type enteric neuron** | Dogiel type II ∩ AH-type | An enteric neuron with Dogiel type II morphology (large round/oval soma, multiple long smooth processes) and AH-type electrophysiology (prolonged afterhyperpolarization >1-2 s, inflection on falling phase of action potential). This combination is characteristic of intrinsic primary afferent neurons across all mammalian species studied. |
| **Dogiel type I S-type enteric neuron** | Dogiel type I ∩ S-type | An enteric neuron with Dogiel type I morphology (flattened angular soma, single axon, short lamellar dendrites) and S-type electrophysiology (brief action potentials, fast EPSPs, no slow AHP). This combination encompasses motor neurons, interneurons, secretomotor neurons, vasodilator neurons, and intestinofugal neurons. |

### Three-axis cross-products (Function × Morphology/Electrophysiology × Neurotransmitter)

These are the "natural kinds" — the leaf-level types where three or four axes converge with high confidence.

#### IPANs (Function × Dogiel II × AH-type × Cholinergic)

| Proposed term | Axes crossed | Definition |
|---|---|---|
| **myenteric intrinsic primary afferent neuron** | C × location | A Dogiel type II, AH-type, cholinergic intrinsic primary afferent neuron with soma in the myenteric plexus, detecting chemical and mechanical stimuli from the gut wall. Represents ~30% of myenteric neurons. Expresses Calca/Calcb, substance P, and CGRP. |
| **submucosal intrinsic primary afferent neuron** | C × location | A Dogiel type II, AH-type, cholinergic intrinsic primary afferent neuron with soma in the submucosal plexus, uniquely sensitive to subtle mechanical stimulation of the mucosa. Represents ~14% of submucosal neurons. |

Safe because: Dogiel II + AH-type + cholinergic + IPAN function is a **1:1:1:1** mapping across all four axes. Every source agrees.

#### Excitatory motor neurons (Function × Dogiel I × S-type × Cholinergic)

| Proposed term | Axes crossed | Definition |
|---|---|---|
| **cholinergic excitatory motor neuron to circular muscle** | C × D × target | A Dogiel type I, S-type, cholinergic motor neuron of the myenteric plexus that innervates the circular smooth muscle layer, causing contraction via acetylcholine and substance P. |
| **cholinergic excitatory motor neuron to longitudinal muscle** | C × D × target | A Dogiel type I, S-type, cholinergic motor neuron of the myenteric plexus that innervates the longitudinal smooth muscle layer, causing contraction via acetylcholine and substance P. |

Safe because: excitatory motor neuron + Dogiel I + S-type + cholinergic is a **1:1:1:1** mapping. Circular vs longitudinal target is a further differentia supported by retrograde tracing.

#### Inhibitory motor neurons (Function × Dogiel I × S-type × Nitrergic)

| Proposed term | Axes crossed | Definition |
|---|---|---|
| **nitrergic inhibitory motor neuron to circular muscle** | C × D × target | A Dogiel type I, S-type, nitrergic motor neuron of the myenteric plexus that innervates the circular smooth muscle layer, causing relaxation via nitric oxide, VIP, and ATP as co-transmitter. Immunoreactive for NOS1 and VIP. |
| **nitrergic inhibitory motor neuron to longitudinal muscle** | C × D × target | A Dogiel type I, S-type, nitrergic motor neuron of the myenteric plexus that innervates the longitudinal smooth muscle layer, causing relaxation via nitric oxide and VIP. |

Safe because: inhibitory motor neuron + Dogiel I + S-type + nitrergic is a **1:1:1:1** mapping. Every source identifies NOS1/VIP as the inhibitory motor neuron signature.

#### Ascending interneurons (Function × Dogiel I × S-type × Cholinergic)

| Proposed term | Axes crossed | Definition |
|---|---|---|
| **cholinergic ascending interneuron** | C × D | A Dogiel type I, S-type, cholinergic interneuron of the myenteric plexus with an orally directed axon, using acetylcholine and tachykinins to relay ascending reflex signals in peristaltic circuits. One subtype in most regions; two subtypes in the proximal colon. |

Safe because: ascending interneuron + Dogiel I + S-type + cholinergic/tachykininergic is a **1:1:1:1** mapping.

#### Secretomotor/vasodilator neurons (Function × Dogiel I × S-type × transmitter)

| Proposed term | Axes crossed | Definition |
|---|---|---|
| **cholinergic secretomotor neuron** | C × D | A Dogiel type I, S-type, cholinergic neuron of the submucosal plexus that innervates secretory epithelium, stimulating water and electrolyte secretion via acetylcholine and substance P. ~42% of inner submucosal plexus neurons in pigs; ~66% co-localize substance P. |
| **VIPergic secretomotor/vasodilator neuron** | C × D | A Dogiel type I, S-type, non-cholinergic neuron of the submucosal plexus immunoreactive for VIP, dynorphin, and galanin, that innervates both secretory epithelium and submucosal arterioles. Comprises ~45% of submucosal neurons. May use ATP as co-transmitter. |

Safe because: both types show **1:1** mapping of function to neurotransmitter identity, and both are uniformly Dogiel I / S-type.

## Cross-Products to AVOID (Unsafe)

| Proposed combination | Why unsafe |
|---|---|
| Descending interneuron × specific transmitter | At least 3 neurochemically distinct subtypes of descending interneurons exist (cholinergic, NOS/VIP/ATP, and others). The function-transmitter mapping is **1:many**, not 1:1. Individual subtypes could be added but require more evidence for precise delineation. |
| Intestinofugal neuron × specific transmitter | Neurotransmitter identity not consistently characterised across sources. |
| Dopaminergic × morphology or electrophysiology | Morphological and electrophysiological properties of dopaminergic enteric neurons are not resolved. Some co-express ChAT, others express canonical DA markers only. Subtyping is still in flux (Recinto et al. 2023). |
| ENC1-4 as individual CL terms | These four excitatory motor neuron subtypes differ by combinatorial gene expression (Calb2, Ndufa4l2, Gda, Penk, Fut9) but their functional differentiation (e.g., which target muscle layer) is not yet mapped. Safe to add as a group ("cholinergic excitatory motor neuron") but not individually until function-marker mapping is established. |
| ENC8 vs ENC9 as individual CL terms | Both are NOS1+ inhibitory motor neurons differing in NPY/Cox8b levels. Functional distinction not yet clear. |

## Notes for Ontology Implementation

1. **Morphology × Electrophysiology equivalence**: The Dogiel II / AH-type and Dogiel I / S-type pairings are so tight that they could be modelled as logical equivalence axioms (Dogiel type II enteric neuron EquivalentTo AH-type enteric neuron). However, modelling them as independent classes with an empirically supported SubClassOf relationship is safer, as rare exceptions may exist.

2. **Dual-function classes**: The VIPergic secretomotor/vasodilator neuron legitimately inherits from both `enteric secretomotor neuron` and `enteric vasodilator neuron`. This is a genuine multi-inheritance case, not an artefact.

3. **Plexus location**: Model using `has_soma_location` some `myenteric plexus` / `submucosal plexus` rather than as a separate classification axis. Location is a differentia within functional types (especially IPANs), not an independent classification.

4. **Transcriptomic subtypes**: The ENC classes from Morarach et al. (2020) are mouse-specific. Cross-product terms at the ENC level should carry a taxon restriction (NCBITaxon:10090). Only add as CL terms when independently validated by electrophysiology or functional assay — currently met for ENC6 (Nmu+/Cdh6+ IPANs) and ENC12 (Nxph2+ IPANs).

5. **Species scope**: All 14 proposed cross-product terms above are supported across multiple mammalian species (guinea pig, mouse, human) unless noted. Taxon-restrict where evidence is single-species.
